# 🍵 Tea Store — E-Commerce Website

A modern and responsive **e-commerce website for a tea store**, built with **HTML, CSS, and JavaScript**.

The project is designed to provide customers with a simple, intuitive, and visually appealing shopping experience where they can browse different types of tea, explore product variants, add products to their cart, and manage their purchases.

## ✨ Features

* 🛍️ Product catalog with different tea categories
* 🍃 Tea varieties and product families
* 🔎 Product search functionality
* 📂 Category filtering
* ↕️ Product sorting by price and name
* 🛒 Shopping cart functionality
* 💰 Automatic subtotal, shipping, and total calculation
* 💾 Cart persistence using `localStorage`
* 📱 Responsive design for desktop, tablet, and mobile devices
* 🎨 Modern and clean user interface
* ⚡ Dynamic product rendering with JavaScript
* 🔔 User notifications and interactive UI elements

## 📦 Product Categories

The store is structured around several product categories, including:

* Green Tea
* Black Tea
* Red Tea
* White Tea
* Blue Tea / Oolong
* Matcha
* Herbal Infusions
* Spices
* Natural Cosmetics
* Home & Natural Products
* Gifts & Special Offers

Each tea family can contain different flavors, formats, weights, and prices.

## 🛠️ Technologies

The project is built using:

* **HTML5** — Website structure and semantic markup
* **CSS3** — Styling, layout, animations, and responsive design
* **JavaScript (ES6+)** — Product management, filtering, searching, sorting, and shopping cart functionality
* **LocalStorage API** — Persistent shopping cart data

## 🚀 Getting Started

To run the project locally:

1. Clone the repository:

```bash
git clone https://github.com/your-username/tea-store.git
```

2. Open the project folder:

```bash
cd tea-store
```

3. Open `index.html` in your browser.

You can also use **Visual Studio Code** with the **Live Server** extension for a better development experience.

## 🛒 Shopping Cart

The shopping cart is fully managed with JavaScript. Users can:

* Add products to the cart
* Increase or decrease quantities
* Remove products
* View the subtotal
* View shipping costs
* View the final total
* Keep their cart after refreshing the page

Cart information is stored in the browser using `localStorage`.
